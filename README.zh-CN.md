# FridgeMind Web Client

*FridgeMind 学生项目的 Vue 3 / Vite 网页客户端。*


[English](README.md) | [简体中文](README.zh-CN.md)

**导航：**[状态](#项目状态) · [本地运行](#本地运行) · [项目文件](#项目文件)


本仓库是 FridgeMind 学生项目的 Vue 3 / Vite 网页客户端。当前源码使用 Element Plus 和 Axios；本仓库本身不声明已经连接到可用的线上后端。

## 项目状态

学生项目网页端；本仓库不声明已连接线上后端。

## 本地运行

~~~sh
npm ci
npm run dev
~~~

还可以使用 npm run build 和 npm run preview。

## 项目文件

- src/：前端源码
- public/：静态资源
- package.json 和 package-lock.json：脚本与锁定的依赖

请勿在公开文档中放置本地地址或凭据。
